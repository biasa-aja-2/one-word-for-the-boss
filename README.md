One word, 30 characters at most, describing the boss: the one who is
always physically looming over your shoulder while you work — hovering
by your desk, hovering in the doorway, hovering over the document you
are still typing.

> Hoverer

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–30 characters, exactly
one word with letters only, no whitespace, no control characters) and
refuses to write if any gate fails, then writes the word to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) with no trailing
newline.
